Elverket × Lars Lerin

Prototypes for image-to-image transitions, point clouds, and particle systems based on Lars Lerin watercolours.

Tools

  • transition-v2 — A→B image transition, WebGPU
  • transition-v1 — A→B image transition, WebGL2

Birds

  • birds-v1 — particle flock with image-based waypoints

Painting series

  • series-v2 — image series with directional particle-sweep transitions
  • series-v1 — image series laid out in a ribbon, particle-sweep transitions

Point cloud

  • pointcloud-v6 — two-image point-cloud transition
  • pointcloud-v5 — point cloud (intermediate revision)
  • pointcloud-v4 — point cloud with cursor interactions
  • pointcloud-v3 — point cloud with cursor wither, click expand, right-click vortex
  • pointcloud-v2 — two-image point cloud with directional scatter
  • pointcloud-v1 — 2.5M-particle point cloud, baseline
  • pointcloud — first point-cloud prototype

Early approaches

  • approach-a-webgl — pixel-level dissolve in raw WebGL/GLSL
  • approach-b-gsplat — gaussian splat dissolve
  • approach-c-hybrid — splat sprites in Three.js
  • approach-d-depth — depth-driven dissolve
  • approach-e-pointcloud — 3D point cloud
  • approach-f-splat — gaussian splat
